# The Oregano Trail: A Merchant's Account

Find it at: https://jvilanova2025.github.io/TOT1/

## Version 1.0

* Desktop browsers only; plays with a mouse/trackpad and keyboard.
* Single self-contained `index.html`; no build step, dependencies, or external scripts.
* Runs entirely in the browser and needs no internet connection once loaded. 
* Progress, best runs and settings save automatically in the browser during play. Clearing the browser's data deletes them.
* The fonts are embedded and are used under the SIL Open Font License 1.1. Copyright and full license text can be found in the `LICENSE` file.
* First public release (October 2026).
